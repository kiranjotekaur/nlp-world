What is NLP?

Natural Language Processing

NLP is a branch of Artificial Intelligence that helps computers understand, interpret and generate human language. We speak with grammar, slang and emotions, but computers only know numbers, so NLP turns language into something a machine can work with.

Where is NLP used?

You use it every single day.

What are its limitations?

Machines are smart, but not perfect.

Chatbot: Scriptbot vs Smartbot

A chatbot is a program that talks to humans using text or voice.

📜

Scriptbot

  • Works on a fixed script / rules
  • Does not learn
  • Limited, only pre-set answers
  • Little or no coding needed
Example: FAQ bot, customer-care menu bot
🧠

Smartbot

  • Uses AI & machine learning
  • Learns from data and users
  • Handles many kinds of questions
  • Complex coding needed
Example: Siri, Alexa, Google Assistant
